# Interview Lab — 개인 면접 연습 스튜디오

혼자서 실제 면접을 연습하고, 웹캠과 마이크로 녹화된 자신의 답변 영상을 확인하며 구간별 타임스탬프 피드백 메모를 작성·비교할 수 있는 로컬 개인용 면접 연습 웹 애플리케이션입니다.

## 실행 방법

```bash
npm install
npm run dev
```

## 주요 화면
- **메인 페이지 (`/`)**: 서비스 소개, 실시간 연습 현황 요약, 핵심 기능 안내, 카테고리별 인기 면접 질문 즉시 연습 시작
- **연습실 (`/studio`)**: 좌측 질문 목록, 우측 실시간 카메라/마이크/화면공유 미리보기 및 질문별 녹화 스튜디오
- **연습 기록 (`/records`)**: 질문별 녹화 영상 재생, 시도 회차 전환(`시도 1`, `시도 2`...), 타임스탬프 구간 피드백 메모(`+ 현재 시간에 메모`) 및 자가진단 저장
- **사용 가이드 (`/guide`)**: 4단계 핵심 워크플로우 안내, 인터랙티브 면접 자가점검 체크리스트, 5점 척도 채점 기준표, 자주 묻는 질문(FAQ)
- **로그인 / 회원가입 (`/login`, `/signup`)**: 로컬 IndexedDB 기반 사용자 계정 생성, 직무 설정, 데모 계정(`demo@interviewlab.kr`) 1초 체험 로그인
- **질문 관리 (`/questions`)**: 카테고리별 질문 추가/수정/삭제 및 줄바꿈 일괄 등록
- **대시보드 (`/dashboard`)**: 전체 질문 및 누적 연습 기록 요약
